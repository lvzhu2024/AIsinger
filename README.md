# AIsinger

> 基于 AI 的音乐生成与创作工具 —— 把脑子里的旋律，变成能听的成品。

**当前状态**：项目初始化中。本 README 是规划稿，会随代码落地持续更新。

---

## 简介

AIsinger 面向音乐创作场景，目标是缩短「一个想法」到「一段可听的音频」之间的距离。
传统流程里，哼出来的一段旋律要变成编曲成品，需要乐器、录音、混音多道工序；AIsinger 尝试用生成模型把这些环节压缩成几步可交互的操作。

适合的使用场景：

- 创作者有了旋律或歌词的雏形，想快速听到一版可试听的 demo
- 需要批量产出不同风格的编曲版本做比较
- 想用特定音色演唱自己的作品

## 功能规划

- [ ] **歌词转演唱**：输入歌词，输出带演唱人声的音频
- [ ] **旋律与编曲生成**：根据和弦进行或旋律动机生成伴奏
- [ ] **音色控制**：切换演唱音色，保留原旋律与节奏
- [ ] **多轨导出**：分离人声、伴奏等分轨，便于后期
- [ ] **风格迁移**：同一首曲子在流行、民谣、电子等风格间切换

> 勾选状态会随实现进度更新，未勾选代表尚在开发或设计阶段。
